# DynoMEM

![Project icon](src/main/resources/assets/dynomem/icon.png?raw=true)

![GitHub license](https://img.shields.io/github/license/SabeeirSharrma/DynoMEM.svg)

DynoMEM is a Fabric mod for Minecraft that reduces memory pressure and improves block-state / shape handling performance by providing optimized in-memory structures and caching.

This mod is based on the original Hydrogen mod by jellysquid3 and FerriteCore by malte0811, updated for personal use.

**Highlights**
- Lightweight, low-overhead caches for block state lookups
- Compact, high-performance fast maps for voxel shapes
- Threading detectors and safety improvements for client-side operations

**Installation**

DynoMEM relies on the Fabric Loader. Users should select Fabric for either the Minecraft launcher (client) or
the dedicated server (server) depending on their needs. Once Fabric is installed, place the DynoMEM `.jar` in the
`mods` folder generated by Fabric.

Fabric installation instructions: https://fabricmc.net/use

**Building from source**

If you're hacking on the code or would like to compile a custom build of DynoMEM from the latest sources, you'll want
to start here.

#### Prerequisites

You will need to install JDK 17 in order to build DynoMEM. You can install this through a package manager such as
Chocolatey on Windows or SDKMAN! on other platforms. If you'd prefer to not use a package manager, you can download
an installable package from Adoptium: https://adoptium.net/.

#### Compiling

Navigate to the directory you've cloned this repository and launch a build with Gradle using the wrapper on the respective platform:

```bash
# Linux / macOS
./gradlew build

# Windows (PowerShell)
./gradlew.bat build
```

The initial setup may take a few minutes. After Gradle has finished building everything, you can find the resulting
artifacts in `build/libs`.

To run the mod in a development client (provided by Loom):

```bash
./gradlew runClient
```

**Project layout (brief)**
- `src/main/java` — main mod sources (`com.sabcancode.dynomem`)
- `resources` / `fabric.mod.json` — mod metadata and assets
- `build.gradle`, `gradle.properties` — build configuration
